GeWu

Self-Evolving Agent Framework for Building Intelligent AI Systems

GeWu is a comprehensive framework for building AI agents with tool execution, memory management, and self-evolution capabilities. The API documentation below provides detailed information for each crate in the workspace.

Core Architecture

Agent Runtime

Loop-based execution with doom loop detection and history compaction

Tool System

Extensible tool interface with panic recovery and timeout handling

Memory

Pluggable memory backends with automatic context management

LLM Providers

OpenAI and Anthropic support with streaming and tool calling

Workspace Crates

gewu-core

Core library with Agent runtime, traits (Tool, LlmProvider, Memory), and message types

gewu-providers

LLM provider implementations (OpenAI-compatible, Anthropic Claude)

gewu-tools

Built-in tools (bash, fs ops, grep, glob, web fetch, MCP, batch, todo)

gewu-storage

SQLite-based persistent memory via sqlx

gewu-cli

Command-line interface application for interacting with the agent framework

gewu-web

Web UI built with Axum and SSE streaming

gewu-graph

Stateful graph execution library (LangGraph-style)

gewu-rag

RAG system with document processing and Qdrant embeddings

gewu-experience

Experience memory with Qdrant vector embeddings

gewu-evolve

Self-critique, Python sandbox, skill library, and tool creation

Quick Start

Build Your First Agent

use gewu_core::{Agent, LlmProvider, Tool};
use gewu_providers::OpenAIProvider;
use std::sync::Arc;

let provider = OpenAIProvider::new("your-api-key", "gpt-4");
let agent = Agent::builder()
    .llm(Arc::new(provider))
    .with_tools(vec![...])
    .system_prompt("You are a helpful assistant.")
    .build()
    .unwrap();
